## 跨日志身份的采纳依据

R2-S02 最初作为契约边界候选提出，原 README 没有逐字规定 token 跨流传输。主会话结合已确认的“只验收展示过的任务结果”与项目及历史 incarnation 身份规则，将其判为身份绑定缺口，补充 token 契约后采纳。相同 merge 结果不能使不同独立交办历史的用户判断自动通用。

此修复不增加真实认证或签名能力；调用者仍是可信适配层。测试断言行为，不固定某一种 token 字段实现。
