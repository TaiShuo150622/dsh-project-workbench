# 桌面验收

目标：用户正在使用的 `/Applications/DeepSeek Harness.app`，共享桌面宿主；不以浏览器开发预览代替验收。只创建明确标记的验收项目和小型 Git 夹具，不触碰现有用户任务。

写前存档：`.acceptance/desktop-before/` 保存桌面 profile 的相关配置、插件版本、项目状态（如存在）。代码提交作为可复现起点；夹具有独立初始提交。敏感配置和完整会话证据不进 Git。

## 已发现的桌面兼容约束

- 当前安装的工具输出 schema 接受标准 JSON Schema `required: ["result"]`；不能照较新源码中的字段级 required 写法猜测。
- 插件自己的会话容器使用独立 slot，再调用 DSH 原生 `conversation.content` factory。重复声明原生 `main.conversation` 的所有权会导致客户端插件启动失败。
- 后端热更新同时需要独立 Loader ID 和独立绝对模块 URL，避免 ESM 缓存保留旧模块。
- 普通 Session 必须加入原生 Workspace，桌面 composer 才可用。仅创建带 cwd 的会话不足以完成桌面接入。
- 标签注册必须挂在插件自己的 effect 上；兼容早期开发版本已留下的同 ID 注册，避免重启桌面。会话导航早于 React 挂载侧栏，自动打开由已挂载的会话头触发。
- 默认代码结果是未提交差异；普通任务不应为写共享 Git 索引额外请求更高权限。最终续做已按此规则通过。
