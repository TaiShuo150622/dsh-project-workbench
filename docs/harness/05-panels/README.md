# DSH 面板平台

> 公开整理版；源版本：未编号；整理日期：2026-11-06。保留原稿历史阶段，未重新运行或复测。内部项目实例、个人原话与私有地址不作为公开附件。


DeepSeek Harness 的通用面板平台：用 `.panel.json` 描述数据与展示方式，面向桌面和终端提供四种内置类型、自定义渲染器、第三方类型与组合面板。
