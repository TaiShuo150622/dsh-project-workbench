本目录保存阅读视图的检查，不能计入产品或模型正确性证据。主稿 v0.1.2 的桌面、小屏、深浅色和图表原尺寸控件已查看；13 份专题的内嵌 SVG 视图，在外部 HTTPS 请求被模拟为不可用时逐页检查了 430px 小屏布局、图数、目录锚点与资源请求。

首次检查发现机制专题的参考式 Markdown 链接未被轻量渲染器识别，长链接文字撑宽页面；已在渲染输入适配层展开标准参考链接，并让长行内文字换行。Markdown 正本不变，图表沿用相同来源 SHA 的已渲染 SVG。初始失败与修复后的回执分别保留。

这些结构检查没有逐像素检查全部专题；主稿及若干截图另做目视核对。最终包若改写导航或增加版本，需要对新增部分重新检查，不能沿用旧稿的结论。
