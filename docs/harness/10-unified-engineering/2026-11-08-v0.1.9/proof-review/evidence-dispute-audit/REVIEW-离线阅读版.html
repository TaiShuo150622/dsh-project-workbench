R13 W11 争议证据与操作政策：模型审查

在固定 W11 提案及其明示的小模型范围内，未发现需修订的实质错误。四态没有被偷换为真实性、独立样本数或行动许可；操作政策确实区别查看、搜证与发布。独立检查增加了撤回/纠正混合排列和直接集合 oracle，未找到模型与声明的冲突。覆盖测量、真实授权和时间窗口键仍是明确未实现部分，不能据此宣称已安全发布或完成产品适配。

本轮是不同执行上下文的模型审查与本地 Python 运行，不是人类审核、一般证明或认证测试。父任务指定不同模型 gpt-6-astra；身份依据是调度说明，不作独立运行时认证。仅写本线目录，原来源、产品及其他作者文件未改，无网络或外部调用。

逐项判断

审查点结论与边界
同命题范围实际 Key 的六字段全部按相等过滤；模型不使用 observed_at 自动合并或覆盖。完整提案还要求 validity window、evaluation regime、operation/recipients 等，state-definition 明列了子集和未建模项。不能把有限键检查解释成现实命题等价解析已经完成。
撤回与纠正Withdraw 只退役指定 observationId，不造负证据；预到达 tombstone 防止晚到原观察复活。Correct 先验证新项及身份，再退役旧项、写入替代项，保留旧记录；这里仅是内存原子性。退役是不可恢复的 ID 状态，需要恢复声明时应使用新 ID。
到达次序作者仅声称所枚举的无撤回四观察排列不影响投影，措辞准确。本轮进一步检查一致身份的混合事件排列；不把结果扩大到同 ID 不同内容、动态资格政策或真实并发存储。
四态与真假BOTH 保留两边；NEITHER 不推出反命题。无关原子没有推理规则，因此不发生爆炸；这不是完整容矛盾逻辑引擎的证明。
重复与独立正负轨分别按 canonical root 去重。同一个根的相反解释仍可得到 BOTH；不同根也保持 independence=UNDETERMINED。根解析及未知 lineage 未实现，稿件已披露。
不可见反证view 本身不实现 ACL；coverage 是另行传入的合成标志。partial/unknown 发布返回 UNKNOWN。若调用方未经实际检查却传 complete，模型不能识别隐藏反证——这是已披露的外部输入前提，不能把输出当完整覆盖证书。
Supported 到操作BOTH 有正支持却不能通过示例 publish 门槛；view/seek_evidence 仍可进入另一层权限检查。READY_FOR_AUTH_CHECK 不是所有业务义务完成，更不是授权；UNKNOWN 也不是事实为假或永久拒绝。
绑定与当前权限错操作、版本、policyVersion、水位的评估不复用。完整适配仍须绑定 coverage、判据、裁决等所有实际读取输入；文稿明确写出。当前授权/实际发送均未计算，没有把准入原子性推广到外部效果。

独立直接检查与针对性差异

oracle_check.py 不使用作者的 Model.view 或 LABELS 来生成预期结果，而是从不可变事件集独立构造断言集、退役集与双轨根集合；共享合成数据类型和键相等语义。它验证的是模型内投影，不是世界事实、认证或根来源真实性。oracle_results.json 保存实际结果与代码 SHA。

  • 5040 个混合事件排列、70560 个中间前缀键投影：七事件包含三个观察、两个显式撤回、两次链式纠正，检查两个版本键。包括纠正先于原断言、替代断言先被撤回、重复接纳同一替代项。每个前缀与独立集合规格一致，最终保留该保留的替代来源。
  • 20736 个资格/状态赋值：四观察分别取 absent/active/retired 与认证/接纳两布尔的全部组合。正负轨、退役及资格过滤一致。
  • 4032 个异键对：扩展到全部六个实际 Key 字段的二值域，包括作者隔离枚举中固定的 history 与 subject；未见跨键污染。
  • 48 个政策格：四态 × 三种 coverage × 四种操作（含未定义操作）。发布需要 SUPPORT_ONLY 且 complete；查看/搜证只进入权限检查；所有结果仍 fact_truth/action_permission=NOT_COMPUTED。
  • 修正原子性负例：新替代项复用已存在 ID 却改变 root 时，拒绝操作且观察、退役集合、事件序列均不变。
  • 四项错误策略差异检查：缺失当否定、最后收到覆盖、仅看正支持释放发布、同根去重顺便消除争议，均与固定参考轨迹不符。这些是针对错误策略的检查，不声称向产品注入了故障。

覆盖声明的最小界限见证：同一仅含正证据的可见 Model，传 partial 得 UNKNOWN；传 complete 得 READY_FOR_AUTH_CHECK，且两者都未计算 permission。这里没有模拟真实隐藏库；该见证准确说明系统必须在模型之外取得有范围的 coverage 依据，不能让调用方标签冒充测量结果。原稿已明示此点，故本轮不另报缺陷。
