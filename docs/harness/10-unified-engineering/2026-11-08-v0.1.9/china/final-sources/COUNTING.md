去重分三层：

1. **精确地址相同**仅共享 URL 查找键，保留每个 catalogue/pointer/SHA、版本和读取范围。fragment 不被悄悄删除。
2. **同文不同表示**用关系表达：同一个目录条目的版本网页/固定源码，以及同一 repository/ref/path 的 GitHub 页面/raw 地址。关系不证明所返回字节完全相同，也不合并读取范围。
3. **记录镜像**须原 JSON 对象完全相等，才标成 `EXACT_JSON_MIRROR`。W11 literature 的两条与 sources/literature 重复；root9 的三条和失败候选与资源目录重复。原对象不删除。

协议版本必须保留：MCP 2025-11-25 与 2026-07-28，A2A v0.3.0 与 v1.0.1，各自有版本前提。A2A 同一版本的 specification.md 和 a2a.proto 是两个文档，尤其不能因同提交而合并其 POST/GET 差异。Node v24.6.0 是发行版 tag＋blob 绑定，不能标成完整 commit URL；Linux 与 Docker 的持续更新的官方文档仅有访问日期，没有冻结它们的现时内容。
