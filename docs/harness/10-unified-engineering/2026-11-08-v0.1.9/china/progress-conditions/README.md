# C-08 自主推进与终止的条件

入口是[讨论稿 v0.1.0](自主推进与终止条件讨论稿-v0.1.0.md)。本专题补充“安全但可能永不完成”的边界，区分控制轮停止、最终验收、服务窗口完成与责任交接接收。C08 编号独立于原 P1–P15、一般 Lean 证明及既有有限模型计数。

- [check_progress.py](check_progress.py)：Python 3.9+ 标准库，无产品导入、第三方依赖、网络或模型调用。
- [results.json](results.json)：21 个有限图配置、全部可达状态和边的数量、fairness 假设及反例。
- [TRACES.md](TRACES.md)：每个配置的可打印最短前缀/闭环，以及最短错误状态前缀。
- [execution_receipt.json](execution_receipt.json)：实际执行版本、代码/结果 SHA 与计数。
- [inputs.json](inputs.json)：9 份既有研究输入的 SHA 与读取范围；不再复制全文。
- [sources.json](sources.json)：1 份形式基础原著的部分阅读记录，不把现有稿件或本轮程序算为新独立文献。

在本目录复跑：

```sh
python3 check_progress.py
```

程序先枚举可达图，再对每个可能闭环入口搜索积状态 `(state, enabledSomewhere, disabledSomewhere, actionTaken)`。循环重复时，WF 要求“某处禁用或确实执行”，SF 要求“从未可用或确实执行”。因此搜索保留可重复状态的闭合走步，不只查简单环。输出在此有限图中最短的“可达前缀 + 公平闭环”；对已失败的有限死端补 `Halt`，明确它是停止后的分析表示。边回放与公平条件另行检查。

可用性在完整图上判断，不能因为搜索时排除了目标状态，就把通向目标的动作错误地当作禁用。有限图上若有避开目标的公平无限行为，其无限重访状态形成强连通子图；可以拼接有限走步，访问这些状态和公平性要求的动作边后回到起点，得到同样公平的周期见证。因此此搜索不只寻找若干手选循环。它仍以这里明确列出的事件图为模型；没有默认把原 TLA 规格、任意执行停顿或真实网络加入图中。

本轮运行覆盖 21 个配置，合计 162 个可达状态、239 条显式边；11 个配置给出避开目标的公平反例（部分是已经停止的拒绝/漏检端点），6 个配置找到指定错误状态前缀。所有预期结果匹配。此处“预期”用于核对反例和故意削弱条件，不是目标系统测试用例通过。无反例结果仅适用于表中状态域与转移。

M07/M15 的奇偶槽是递增版本/义务 ID 的有限抽象：每个抽象回路均可用不断递增的真实 ID 提升，不表示许可复用旧身份。M08 阶段推进的有效性、M10 接收者的合格且愿意接管、M13 的时间上界均为明确前提，没有由程序验证现实含义。

原预算 Lean 证明保持不变；本轮没有调用 Lean/TLC、运行产品或启动外部任务。一般条件只有纸面论证与有限辅助证据，尚未完成实现精化或一般机器证明。讨论稿的离线 HTML 是阅读视图，按 skill `--offline` 生成，图暂以 Mermaid 源码显示，没有远程脚本；Markdown 是正本。若后续内嵌 SVG，应记录新的渲染回执，不能沿用其他稿的视觉检查。
