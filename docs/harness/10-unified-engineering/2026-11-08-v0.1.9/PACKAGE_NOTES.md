# 阅读副本与证据身份

本目录是本地整理的派生阅读包，尚未公开发布。当前来源目录及固定源码的历史身份仍以各自回执和 SHA 为准；根目录 PACKAGE_MANIFEST.json 标识本包实际字节。

- 个人主目录和随机临时目录被替换为 __LOCAL_HOME__ / __LOCAL_TMP__。这类回执是路径脱敏副本，不是原始执行输出；原件保留在本地研究集。
- 当前阅读页中出包的旧公开稿及产品文件链接，转为实际存在的固定 Git 提交链接。打开这些外部参考需要网络；本包页面与内嵌图表本身不依赖它们加载。
- 冻结 inputs 的旧相对链接保持历史形式，有些只在原位置成立。阅读请从 README 的当前入口进入；不要把冻结快照当导航页。
- 相邻 *.render-receipt.json 是导出前的渲染阶段回执，output_sha256 指当时原视图；PACKAGE_VIEW_IDENTITIES.json 连接它与包中最终视图。新生成的 *.reading-build.json 分别记录渲染前后处理的两个输出身份。
- 历史 SHA256SUMS 和 *_PASS_MANIFEST.json 描述各次输入或接收时的字节。它们不承诺与脱敏/链接转换后的本包逐字节相同；DERIVATION.json 给出原始与派生哈希对应。
- 在线 Mermaid HTML、构建中间页、工具链二进制、浏览器缓存和本机边界扫描目录不进入此包。模型、配置、错误轨迹和负对照不会因结果失败被删除。
- DSH 固定源码片段/文件作为复核输入保留，附 third-party-notices/deepseek-harness/LICENSE。该许可针对相应第三方源码；本包没有替资料所有者授予全部研究文档新的开源许可。

复跑先读 REPRODUCE.md。真实产品、认证入口、外部效果、迁移和任务收益仍按 EVIDENCE.md 的状态理解。
