核心对象中文速查

这是阅读辅助，不是冻结 API 或新 schema；研究语义不表示产品已全部实现，普通小编辑只用必要部分。例子沿用假想链接检查器，均未运行。比较证据前须对齐历史代际、对象与版本、判据、时间和主体／用途／接收范围，不把不同问题报成冲突。

Task／spec工作单元及其版本化要求v1 查文件，v2 加锚点改规格需重判；备注不必改规格形式§1、3

材料怎样成为判断

词条中文含义小例子最易混淆的边界本轮材料
event被接纳入日志的记录记录规格改为 v2提交顺序不是世界发生顺序；接纳不保证内容真形式§2
observation某来源对对象的观察API 报告 r2 成功来源身份真实不保证内容正确；世界还会变化形式§1、3
evidence／四态同一命题的正负依据；无、仅正、仅负、两者都有r2 有相反回执“支持”只记正证据存在；不裁定真值。同根重复不增加独立证据，不同根也未必独立形式§3
Assessment按操作、政策、水位及覆盖评估证据可查看争议，发布待查尚未裁决可保留未知；操作授权另核主稿：完成语义
Recorded／Supported／Usable／Accepted曾记完成声明／证据符合完成判据／本次消费有可用依据／当前验收适用v1 验收不能直接套到 v2四者不等价；Supported 不是仅有正证据；Usable 是账本判断，非永远可读形式§3

范围、上下文与权限

词条中文含义小例子最易混淆的边界本轮材料
coverage指定有限域在固定切点是否按约定处理检完两条义务，一条失败complete 不等于任务完成；拒绝访问不能删分母，未知边界仍未知覆盖稿
watermark带历史身份的处理或读取切点整理至10，调用需补11不同历史的10不可互换；不是世界时钟或全覆盖证明形式§2、覆盖稿
Principal／当前 Grant命名空间中的主体及当前适用授权可读 s2，不可发布自报 actor 不认证；历史批准或上下文文字不自动成为当前授权形式§1、5、架构§4
ContextManifest实际上下文的材料、版本、义务与缺项清单列出新约束和未读尾部有引用不证进入请求；进入请求不证正确使用，也不授予权限形式§6、覆盖稿

接续责任与依赖

词条中文含义小例子最易混淆的边界本轮材料
owner／handoff义务责任者与明确接纳的接管决定新控制器接查 a1保留原动作及代际；换人不清 unknown 或未结算负担，保管不等于有能力解决形式§7、例子阶段6
settlement确认费用入账，并按证据调整剩余负担已花未报8仍须占位取消 ACK 或产物可读不证明发送者终止、无迟到写入或费用结清形式§7、例子结尾
typed graph标明关系类型的图产物依赖与证据支持分边受影响不等于全部失效；工作流可循环，不要求所有关系都是 DAG形式§4

一条阅读链：规格 → 尝试 → 动作与发送 → 观察／事件 → 证据与评估 → 当前版本的完成、消费和验收判断。每次行动另核当前授权；覆盖、未知效果和未决负担不能被箭头省略。
