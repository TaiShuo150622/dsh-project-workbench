1. 审批、恢复与外部效果

OpenAI Agents SDK HITL，固定提交，定位 Keep approval state on the server、Recovering after a crash：RunState 反序列化不认证快照或提交人；审批不能保证 exactly-once。目标端原子幂等或权威对账仍由应用负责；结果未知时不自动重放。它直接反驳“持久审批快照足以安全重试”。

Codex 用户验证协议，固定提交，定位 UserVerificationCancelResponse：ACK 仅确认取消信号，原生工作可能尚未退出，完成效果不回滚。只适用于该实验性原生用户验证 RPC，不能泛化成所有 Codex 工具取消协议。

OpenAI 托管 Agents API 恢复，定位 Recovery：stream 断连不确定 turn 最终状态；失败 turn 可能已经改文件或调用外部工具，重试前应查已发生作用。

2. 会话、执行与环境必须分开

OpenAI sandbox lifecycle，定位 Keep the environment available or stop it、Reconnect after a disconnect：idle 单个事件不足以安全关机；中途断连可能令工具失败但 turn 仍完成；不会自动重启被杀命令。环境控制器应处理签名 webhook，入队后回成功，再读当前状态，不能按过时事件直接启动资源。

Anthropic Managed Agents 架构原文，2026-04-08：session 日志、harness 和 sandbox 分离，harness 可从日志重建；sandbox 故障作为工具错误反馈后可另建。这里的可恢复不保证原进程继续或外部效果原子提交。

3. 程序完成、评分通过和产物可取是三个事实

Claude Workflow runs，定位 Run events、Interrupt a session with runs open：completed 只说明工作流结束，线程失败仍可被程序处理后完成；phase_ended 不证明通过；workflow_run.error 不是终止事件。主线程 interrupt 不结束 workflow run，后者可能继续或暂停。

Claude Define outcomes：独立上下文 grader 按 rubric 评分，达到目标或用完有限迭代后结束。satisfied 是评分器输出；产物在 session idle 后可能仍需等待上传才可列出。我们的推断：验收应绑定可取得的产物、验收规则版本与证据，不能仅映射 idle 或 satisfied。

4. 权限和上下文不是同一层

Claude Managed Agents permission policies：auto 不是人工检查点；自定义工具由应用执行，不受该策略代管。将不可信终端用户内容转为 user.message 会使自动评估视为调用方意图；要由应用守住身份与权限边界。

Claude Code memory：CLAUDE.md 与 auto memory 属上下文，不是强制配置。主题记忆按需读取，索引有启动读取上限。我们的推断：Record 上下文组装不能授予动作权限。

6. v0.1.1 新增优先复核

  • OpenAI automatic review：核对“Choose a review mode”和“Change the review mode”。默认none不转人工；模式变更要求idle和输入稳定，仍应处理竞态409；root/subagent均适用。
  • OpenAI sandbox security：核对“Separate credentials”。托管控制面有应用权限与executor连接凭据区分，不能写成只提供session/runtime；最终用户业务对象授权仍是另一层。
  • Claude managed memory：核对“Safe content edits”“Audit memory changes”“Redact a version”。已有版本/CAS/审计和历史内容清除；别把这些写成Record独有，也别把正文immutable解读为内容永久不可删。
  • Claude self-hosted memory：核对“How the worker handles memory”和“Read-only stores and conflicts”，尤其工具成功但同步冲突覆盖且代理不收错；仅适用自托管副本。
  • Claude mirror固定源码：timeout可能迟到落库故不重试；一般异常另有最多3次尝试；不能写成所有失败都不重试。
  • Rajasekaran全文：复核“The architecture”“Removing the sprint construct”“Results from the updated harness”。v0.1.1正文已列公开样例和局限；没有宣称可复现统计基准。末尾QA是取消每sprint检查，不是整个任务只一次检查。
