四条最少必要的桥接

B01 浏览器调用、业务效果与操作摘要分开。 OPERATION-LOG 第 14、21–24、31–44、130–140 行说明日志可关闭、尽力写入、截断/轮转、无防篡改且只覆盖工具 wrapper；ok 仅指工具正常返回。它适合诊断，不能直接成为 Record 的权威提交或业务完成证明。CONTRACTS 第 13–27 行的连接 generation、runId/callId/owner，需在未来适配层显式关联到 history、attempt、action、provider/context/tab 代际及最终参数。连接重建使旧 RPC ID 失效，不等于原操作未生效；页面提交后失联仍保留 unknown，另做目标效果观察。派生摘要保留缺口，关键效果来源另作受范围约束的证据引用，不把秘密或页面正文塞入诊断日志。

B02 浏览器租约只是局部控制，不是效果围栏。 LEASES 第 6–10、47–52、89–99 行明确该历史阶段仅有内存基础，未统一接写动作，provider 重启丢失，takeover 后可再次申请。未来接 I03/I04 时，先证明实际写入口覆盖，再把 owner 从可信主体派生，并绑定正确实例/标签页代际。TTL、导航、关闭、用户接管只能改变后续控制资格；不能回滚服务器已接受的请求，也不能单独证明旧发送者停止。LIFECYCLE 的资源释放不变量应作为待验证契约；长任务期间是否可清理 profile/capture/下载引用，应由拥有者、在途动作和证据保留要求共同判断。

B03 权限、能力、页面材料与执行位置分别映射。 SECURITY 第 21、27–36、52 行保留页面不可信、目标 origin、截图/下载会话归属和个人本机边界；CAPABILITIES 第 101 行明确声明能力不等于当前可用。未来适配器应记录最终目标 origin、对象/参数版本、批准适用范围与执行位置；审批后页面/对象变更须依当前策略重新判定，不能把旧批准移给新对象。数据进入 Record/模型时保留消费者与接收范围，访问句柄不变成授权。项目在远端不表示浏览器、登录态或文件上传也应转移到远端；SECURITY 的本机保证不能自动覆盖 A/B 远程模式。此桥接不改用户已有审批选择，只要求固定实际策略与强制点。

B04 实时输入先有可修订来源，再进入决定与行动。 实时讨论稿 第 31–43、45–55 行已经区分 User/Person/SpeakerLabel、输入文本版本、临时/稳定状态、参与者陈述/决定/AI 推测以及慢检索。最小新契约是：片段绑定资产位置、版本与采集/接纳时点；改口 supersede 旧断言并更新投影，原依据仍可查；说话人标签或稳定转写本身不授予行动权限。慢检索返回时核对问题版本、当前目标、材料水位与访问范围，过时结果可留作历史，不能覆盖当前决定。建议将它作为 I05 的一种输入夹具；先验证一段输入→修正→晚到结果→当前上下文，不先造语音平台。已发送的外部动作不会因转写修正被自动撤销。

这四条是本轮桥接提案，尚未写入主稿、现有 I 清单或产品代码；不增加默认实验组。若未来把浏览器动作选作真实效果样本，需另定其目标和结果契约，不能伪装成 S1 普通 PR merge。

历史文档中的待核对点

  1. CONTRACTS/LIFECYCLE 写的是 0.2.21 / 3014180，LEASES 为 0.1.98，CAPABILITIES 为 provider 0.1.87。它们不是同一次运行的能力快照，不能拼成“当前全部支持”。
  2. CONTRACTS 把 runId/callId 关联到 operation log，OPERATION-LOG 的严格字段表却不列它们。当前只能登记文档映射缺口，需以后读对应固定源码确认；不能先假设已经有可恢复的调用身份。
  3. APPROVAL 早段建议独立审批，§5/§11 又明确记录后来选择 follow-dsh；“硬敏感始终问”的目标清单与“部分尚未接入”也并存。应保留版本/决定先后并核查实际路径，不自行恢复更早默认值或新增审批流程。
  4. CONTEXTS §6 说尚无 chrome_verify，§7 又描述其接口，产物目录的说法也不同。暂不把此文档当真实断言编排已完成的证明；浏览器验证产物及存续范围仍待固定代码/真实回执。

没有浏览器产品源码或运行回执的新检查，因此以上是源内阅读发现，不是当前漏洞、故障或验收结论。其他平台路线、密码管理/跨通道专稿、Windows 队列和性能数字只保留索引入口；没有把未读条款作为新契约依据。

最终阅读包的收口方式

核心路线仍为主稿 → 七片任务书 → 一个 Coding 交付 → 远程/长期任务；浏览器按 B01–B03 作为能力专题加入，实时讨论按 B04 作为输入专题加入。旧版本、画板和平台扩张放可选历史入口，不阻塞首片，也不从归档消失。

公司与量化内部材料不在本包输入内；公开稿中出现的通用思想只按其公开边界引用。未读附件保持 INDEX_ONLY，哈希只证明文件身份，不证明已经理解或实现其内容。
