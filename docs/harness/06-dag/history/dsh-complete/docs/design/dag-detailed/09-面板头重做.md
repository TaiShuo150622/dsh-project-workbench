### 2.1 面板从窗口那一条下面起（2026-10-21 补）

> 公开整理时略去非公开项目实例或个人会话来源；通用设计仍见本节其他内容。

改法：面板（停靠、全屏都一样）的顶 = 宿主在根元素上发的 `--dsh-frame-top-clearance`，缺省 0。

| 在哪 | 这个值 | 面板顶 | 窗口那一条里有什么 |
|---|---|---|---|
| Mac 桌面版（`html[data-platform=darwin]`） | 48 px | 48 px，顶边一条 1 px 线 | 红绿灯、侧栏开关、会话标题、「DAG」按钮 |
| Windows 桌面版（`html[data-windows-titlebar]`） | 标题栏高 | 标题栏下面 | 系统的最小化 / 最大化 / 关闭 |
| 浏览器版 | 没有 | 0（照旧） | 浏览器自己的标签栏在页面外面 |

全屏 = 窗口那一条下面整块；那一条（含「DAG」按钮，点它也能关面板）始终露着。这个值是 DSH 自己公开的（`@deepseek-ai/dsh-client-ui-layout` README「Window-chrome seat」：主面板里的入口页也按它往下让），不是猜的像素。

## 3. 宽度档（按面板自己的宽，不按窗口）

档的门槛照画板 `PanelHead.dc.html` 的 `bS / bM / bL`：

| 档 | 面板宽 | 行内（从左到右） | 进「⋯」的 |
|---|---|---|---|
| S | < 720（最窄 560） | × · ⤢ · ‹ · › · 面包屑 · 🔍 · 场景 ▾ · ⋯ | 来路 |
| M | 720–979 | × · ⤢ · ‹ · › · 面包屑 · 来路 ▾ · 🔍 · 场景 ▾ · ⋯ | — |
| L | ≥ 980 | × · ⤢ · ‹ · › · 面包屑 · 来路 ▾ · 220 宽搜索框 · 场景三颗 · ⋯ | — |

- ‹ 只在**有来路**时出，› 只在**能前进**时出（G6：不画灰按钮）。
- 面包屑是唯一的弹性项：下限 120 px；放不下先截根级和中间级（省略号），**末级不截**。
- 「设计稿」不进行内，只在「⋯」里（它是开发素材，不是场景）。
- 600 px 宽实测要的宽度：× ⤢ ‹ › 4 × 28 + 面包屑 ≥ 120 + 🔍 28 + 场景 ▾ ≈ 72 + ⋯ 28 + 间距 ≈ 400，放得下。

## 4. 每一项

尺寸一律照画板：行高 40，左右内边距 8，项间距 4；按钮高 24、最小宽 24、平时**无边框**，悬停出 1 px `--line` 边；
字 12 px / 16 px，`--dag-font-sans`。

| 项 | 长相 | 什么时候出 | 点了 | 悬停提示（title） |
|---|---|---|---|---|
| 关闭 | `×`（14 px） | 恒在 | 关面板（宿主的历史、每屏选中都留着，下次开回到这一屏） | 关掉面板 |
| 形态 | 停靠时 `⤢`，全屏时 `⤡` | 恒在 | 停靠 ↔ 全屏 | 铺满整个窗口 / 还原成停靠 |
| 后退 | `‹` | 影响面、且有来路 | 回上一屏（有缓存直接重推，≤ 0.5 s） | 后退：{上一屏的名字} |
| 前进 | `›` | 影响面、且能前进 | 去下一屏 | 前进：{下一屏的名字} |
| 面包屑 | 根级 › … › 末级 | 恒在 | 根级、中间级能点的是蓝字；末级加粗、不能点 | 每级的全名 |
| 来路 | `来路 ▾` | 影响面、来路 ≥ 2 屏；S 档进「⋯」 | 开 R1x「来路」 | 这次打开面板之后看过的几屏 |
| 搜索 | S / M：`🔍` 图标；L：220 宽框，占位字「搜名字或问一句（/）」 | 页面能换焦点时（§5） | S / M 开 R1x「搜索」并聚焦输入框；L 直接在框里打字，结果出在 R1x | 搜名字或问一句（/） |
| 场景 | L：三颗 `① 影响` `② 待拍` `③ 架构`，当前那颗按下（实心 ink 底、白字）；S / M：一颗 `{当前那颗} ▾` | 页面报了 ≥ 2 个场景（§7 `ready.page.scenes`） | L 直接切；S / M 开 R1x「场景」 | 各场景全名（改之前看影响 / 待拍的决定 / 整个项目） |
| 更多 | `⋯` | 恒在 | 开 R1x「更多」 | 更多：明暗、看设计稿、重新读取、构建 |

### 4.1 面包屑写什么

根级 = 这一屏回答的问题的短名（G7：场景名只在这里出现一次）；末级 = 现在看的那个。

| 在看什么 | 面包屑 |
|---|---|
| ① 影响面，焦点 example.py | `影响面 › example.py` |
| ① 影响面，还没选焦点（页面没带内联视图） | `影响面` |
| ② 待拍 | `待拍的决定`（页面报了更细的一级就接在后面，例 `待拍的决定 › TASK-EXAMPLE`） |
| ③ 整个项目 | `整个项目` |
| 设计稿 | `设计稿 › I-01 ① 影响面` + 末尾一枚灰色小标 `样例数据` |
| 从聊天里点「在面板打开」来的那一屏 | 根级前面多一级蓝字 `聊天`：`聊天 › 影响面 › example.py`；点「聊天」= 关面板、滚回聊天里那张卡并描一圈边；悬停提示带上聊天那句抬头 |
| 旧页（v1，`#graph-data` 能切开） | `项目图 › {焦点名}` |
| 静态页（设计稿单页，没挂真数据） | `设计稿` + `样例数据` |
| 旧渲染器（`graph/read` 退路） | `项目图（旧渲染器）` |
| 正在打开 | `项目图` + 灰字 `正在打开…` |

「从聊天来」原来是头下面单独一行（带聊天那句抬头 + 「回到聊天」+ ×）；现在并进面包屑根级。
抬头那句在页面答案区里已经有了，头里不再说第二遍（G7）。

## 5. 搜索（R1x「搜索」）

- **打字就出**：先搜宿主手里这一屏的载荷（本地，按键就出，标「这一屏」），停 150 ms 再问后台整张图（`graph/search`，
  只要文件 / 模块 / 函数 / 类，不要测试），两组合并去重，最多 8 行。
- 一行 = 类型牌（文件 / 函数 / 类 / 模块，灰）· 名字（加粗）· 出处（等宽、灰，放不下截前面）·「这一屏」小标（本地命中才有）。
- ↑ ↓ 选，回车 / 点 = 以它为焦点打开影响面；人在 ②③ 时先切回 ① 再开。Esc 先清字、再收起。
- 最后一行恒在（框里有 ≥ 2 个字时）：「交给模型问：『{框里的话}』」——塞进 DSH 输入框、不发送
  （塞的是「在 DAG 里帮我看看：{话}。先用 graph_impact / graph_show 查，再回答。」）。
- 没命中：「没搜到『xx』」+ 上面那行「交给模型问」。整张图那一路失败：尾行灰字「整张图里搜不动：{原因}」，本地那一组照出。
- 快捷键：面板开着、焦点不在输入框里时按 `/`：L 档聚焦框，S / M 档打开这一行。
- 旧页（v1）：只有本地那一组（载荷在页面里），尾行是「按这句话挑一组：『xx』」（走出示 agent，原「问一句」按钮）。
- 静态页、旧渲染器：不出 🔍（G6）。

## 7. 宿主和页面怎么分（面板协议 v2 加字段，不加名字）

接 `08-面板协议v2第一版.md`；只加字段，名字表 `web/graph/proto/messages.js` 不变。

| 方向 | 消息 · 新字段 | 意思 |
|---|---|---|
| 下 | `env.head: 'host'` | 宿主画 R1：页面别画自己的后退 / 前进 / 搜索 / 面包屑（影响面页的工具行），也别画场景导航条（studio 的 st-bar）。没有这个字段（旧宿主）就照旧画 |
| 下 | `env.scene: string \| null` | 宿主头上现在是哪个场景。多场景页（studio）照它切页；页面自己切了页（画板里的链接）就报 `summary`，宿主只记下、**不回发**（不然来回打转） |
| 上 | `ready.page.chrome: string[]` | 页面认哪些：`'head'` = 收到 `env.head` 会藏自己的工具行；`'scenes'` = 认 `env.scene`。宿主只在页面认 `head` 时才画 ‹ › 搜索面包屑，免得新宿主 + 旧页面两份搜索框 |
| 上 | `ready.page.scenes: [{scene, short, name}]` | 多场景页有哪几页。studio 中转影响面子页的 `ready` 时补上（`short` = 按钮上的字「① 影响」，`name` = 面包屑根级「影响面」） |
| 上 | `summary.crumb: string[]` | 非影响面场景的面包屑（≤ 3 级，每级 ≤ 40 字）；没有就用 `scenes` 里的 `name`。影响面的面包屑宿主自己从历史里拼 |

`summary.title` 照旧发、宿主照旧收，但**不再写在头上**——只放进那一级面包屑的悬停提示（那句在页面答案区里本来就有）。

新旧搭配：

| 宿主 \ 页面 | 新页面（认 head） | 旧页面 |
|---|---|---|
| 新宿主 | 一行头，页面不画工具行 | 一行头只有 × ⤢ 面包屑 ⋯；页面照旧画自己的工具行（两边不重复） |
| 旧宿主（c0072789 之类） | 不认 v2 → 本文 R0-4 之前的老毛病；装新插件解决 | 照旧 |

## 10. 替你定的默认（看过再说改不改）

1. **头由宿主画**，不是页面画：页面死了、卡住了，× 和 ⤢ 还在；后退前进和搜索本来就是宿主管的（历史、`graph/search` 都在宿主）。
2. 场景键用 studio 现有的字「① 影响 / ② 待拍 / ③ 架构」，面包屑根级用全名「影响面 / 待拍的决定 / 整个项目」。
3. 「设计稿」收进「⋯」，不和三个真数据场景并排。
4. 「从聊天来」并进面包屑根级「聊天 ›」，不再单占一行；聊天那句抬头只在悬停提示里。
5. 构建号平时只在「⋯」诊断行；对不上才上 R0 琥珀条。
6. 「交给模型问」放在搜索结果最后一行，不单独占一颗按钮（原「问一句」）。
7. 旧页（v1）的「全貌 / 待拍 / 还欠什么」当成它的三个场景，用同一个场景控件；它的选中行（换焦点 / 交给模型）留着，挪成 R1x 的一行。
