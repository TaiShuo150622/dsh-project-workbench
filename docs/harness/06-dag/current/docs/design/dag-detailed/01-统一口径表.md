## 通用术语与契约分层

统一词表应明确实体身份、来源、时间、新鲜度、动作与回执，避免各页面用同一个名字表示不同对象。

| 层次 | 通用责任 |
| --- | --- |
| 实体与关系 | 稳定标识、实体类别、来源、关系方向与证据强度 |
| 时间与变化 | 时间窗、信息可用时点、版本差异与新鲜度 |
| 视图声明 | 需要回答的问题、选取范围、可见字段与解释 |
| 卡片与布局 | 语义内容、几何尺寸、折叠档位、焦点与强调 |
| 动作与回执 | 授权边界、请求身份、执行结果、拒绝与未完成状态 |
| 构建与兼容 | 数据与视图版本、构建来源、兼容失败的明确反馈 |

## 冲突处理
