## 通用设计目标

项目图面板用于解释改动影响、待决问题、架构进度及对话中的证据。图、表和文字应指向同一组来源，设计样例与真实运行结果分别标识。

- 按当前问题选择有限子图，保留返回全貌与来源的入口。
- 以结构、材料和有出处的关系构成数据模型；派生索引可重建。
- 在不同宽度使用语义档位和折叠，保持文字可读，不用整体缩放掩盖拥挤。
- 说明新鲜度、缺失、失败、权限与未验证状态，避免用视觉上的成功代替事实。
- 路径和数据投影在所有出口采用一致规则；公开样例必须是独立合成材料。
- 与模型的交互保留人工确认，呈现结果与执行动作分开。
