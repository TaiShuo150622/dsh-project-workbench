## 通用布局分层

布局引擎将语义视图转为有界几何结果，语义选择、测量、布局、走线、检查和渲染分别承担责任。

```mermaid
flowchart LR
 A[语义视图] --> B[尺寸与预算]
 B --> C[布局]
 C --> D[走线]
 D --> E[几何检查]
 E --> F[渲染与回执]
 E -. 有界重排 .-> C
```

从左向右的过程应可复现；重排必须有终止条件，回执应说明超限、裁剪与未显示内容。

## 可复用约束

- 语义结构与几何位置分开，后端不靠坐标表达业务关系。
- 输入顺序变化不应无故改变相同身份对象的布局。
- 卡片测量、列宽、边路由和容器尺寸都纳入预算。
- 支持竖排与横排的适用范围，超限时降为可读列表或分组。
- 展开、收起、焦点和视口更新保持稳定，避免反复振荡。
- 检查边交叉歧义、遮挡、文字溢出、不可达内容与键盘路径。
- 资源数字必须由目标环境实验得到，设计预算不作为已达到的性能。
