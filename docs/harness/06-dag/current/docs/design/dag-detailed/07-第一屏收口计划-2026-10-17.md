# 07 · 第一屏收口计划（A：场景①「改之前看影响」）

> 公开摘编；源版本：未编号，2026-10-17；整理日期：2026-11-06。保留通用计划和历史状态边界，未重新运行或复测。原稿所依赖的非公开实现、全仓基线、实际数据、执行命令、提交与原始会话记录未收录；本件不是原始验收包。

## 0 · 目标

将「改之前看影响」从设计稿与独立组件推进到可读页面：先以合成夹具生成静态单页，再接入授权的影响数据，最后通过功能开关接入 DSH 面板。历史计划只覆盖第一屏，不把其他场景、编辑写回和动效混进同一阶段。

## 1 · 历史判断

原稿认为设计已足够开展第一屏工作，主要缺口在页面装配、数据适配、宿主接入和验收。这里保留判断及其适用日期，不复现原项目逐文件现状，也不将它当作当前工作台仓库的实现清单。

## 2 · 本阶段默认方案

| 事项 | 历史计划采用的方案 | 边界 |
| --- | --- | --- |
| 布局内核 | 沿用既有试验的 A 内核方向 | 不将试验结论扩大为所有布局场景的通用结论 |
| 走线 | 箭头挂中线，热区用于命中；列内采用有限通道 | 无法画出的边应有计数说明 |
| 影响面 | 第一屏只展示向前传播的影响边 | 同跳、回边与其他关系暂不混画 |
| 宽度适配 | 采用竖排流和横排分层，保留窄档最小卡片数 | 临界宽度的方向切换需要回差 |
| 接入顺序 | 静态单页与假宿主先验收，真实宿主后接入 | 卡内图、原地长卡和展开留待后续 |
| 可读性 | 位置行不低于既定字号，复用组件颜色与列头规则 | 不以压缩文字来掩盖布局溢出 |
| 数据边界 | 先完成影响数据排除规则和导出投影 | 真实数据接入前完成必要的访问与隐私处理 |

## 3 · 范围

第一屏由答案区、改动集条、只读检查条、影响面画布、文字带和尾行组成。画布包括种子卡、受波及卡、组卡和枢纽卡；展示前向边、证据层级、强调、图例和未画线计数。页面需考虑等待、失败、上一份留底与陈旧状态。

本阶段不做其他三个场景、编辑写回、完整动效、卡内小图、边卡原地长出、跨天布局记忆、跨项目与多观者权限投影。不能将后续预留当作本阶段已有能力。

## 4 · M0–M4 工作分解

### M0 · 基线冻结

核对分支与已有组件、布局的关系，运行相关检查，登记已有失败与 INCOMPLETE 项。产出可追溯的基线说明；原项目全仓检查数量不作为当前公开插件的验收证据。

### M1 · 静态第一屏

装配页面骨架、列头、列组头和空列结论，使用合成夹具调用真实布局入口，再由组件渲染。按 560 / 893 / 1440 三档宽度及浅深主题检查；预测高度应与浏览器 DOM 实测相符。机器检查之后仍需人工确认页面结构与可读性，此时不接真实数据。

### M2 · 接入影响数据

先核对数据服务是否提供闭包、跳数、名次、路径、检查项与计数，只补第一屏所需字段。将影响载荷适配为布局规格与视图模型；列语义和名次应来自场景数据，不能从展示文字猜测。补等待、失败与上一份状态，检查条只展示不执行。导出前完成排除规则及投影，再用单页和假宿主检查授权数据下的页面、未知态与失败态。

### M3 · DSH 面板接入

以功能开关和页面版本对账接入新前端，保留旧面板回退方式。宿主变更包括协议、页面常驻、切换视图推送载荷和主题传递；应集中变更后验证，不反复打断宿主。验收覆盖真实面板中的三档宽度、人工可读性与回退路径。

### M4 · 收口

补齐第一屏使用的画廊场景、测试和变异检查，在干净工作树复核，并更新交接说明。机器结果、人工检查和未完成项分别记录。原稿的估时属于当时的条件估算，本公开摘编不把它作为当前排期承诺。

## 5 · 验收尺子

| 层次 | 第一屏需要满足的条件 |
| --- | --- |
| 机器检查 | 组件与边线检查无违规；预测高度与实际 DOM 高度一致；相同载荷在同档宽度下确定性渲染；新增断言能发现刻意破坏；单页可离线打开 |
| 人工检查 | 在真实 DSH 面板中能读出影响对象、检查优先级、建议检查项和关联文字 |
| 页面检查 | 560 / 893 / 1440 各档可读；字号不低于规范；无文字重叠；线不穿卡片与列头；未展示的边有计数 |
| 发布状态 | 代码检查通过不能代替真实面板人工验收；缺一项就明确保留 INCOMPLETE |

## 6 · 风险与依赖

组件规格尚未冻结会导致返工；字段不足会扩大数据适配工作；导出投影未完成会阻止真实数据接入。宿主接入需安排验证窗口，分支同步需避免冲突，已有失败要与本次引入的问题分开记录。范围若扩回多场景，应重新讨论计划。

## 7 · 给后续场景保留的接口

按视图键装配页面，节点类型通过登记表扩展，选择、展开、导航、动作和布局回执不绑定第一屏。执行与协同图将来可复用渲染层，但在本稿阶段不视为已经实现。
