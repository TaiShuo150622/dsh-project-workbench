## 怎么填

- **喜欢的 5–10 张，不喜欢的 3–5 张**。不喜欢的同样重要——上一版「太普通」，正是因为只说了要什么、没说不要什么。可使用有权公开的界面截图作为反例，并明确理由；原讨论中的私人截图未随文集提供。
- 每张写**具体是哪一点**，不要只写「好看」：字（大小、粗细、字体气质）、间距与密度、颜色（多还是少、亮还是暗、强调色怎么用）、线（粗细、直角还是曲线、虚实）、卡片（有没有边框、阴影、圆角）、图标、动效、整体气质（安静 / 精密 / 活泼 / 像图纸 / 像笔记）。
- **想用在哪**：面板整体、卡片、连线与箭头、架构图的泳道与列、聊天里的小块小图、状态（出错 / 过时 / 在跑）。
- 截图放在同目录新建的 `refs-visual/` 里，文件名写进表。截图别带个人信息，也不要包含未获授权的项目页面。

## 之后怎么用

1. 主会话据这张表写《视觉方向提示词》：一个能叫出名字的方向 + 参考图逐张说明「照它的哪一点」+ 明确不要什么 + 与网格尺寸体系对齐的字号 / 间距节奏；
2. Claude Design 第 0 轮：只画场景③架构图（893 宽）一张，出 3 个明显不同的方向并排；
3. 你挑一个或混搭 → 定成一小套设计系统（token + 组件）→ 再按《03 上传清单》第 1–4 轮画全部画板。
