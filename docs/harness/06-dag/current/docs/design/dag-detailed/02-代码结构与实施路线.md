## 通用架构边界

图数据提取、领域事实、视图选择、布局计算、组件渲染和宿主接线应分层，使前端重做与后端数据演化可以独立验证。

```mermaid
flowchart LR
 A[来源与数据提取] --> B[实体关系与版本]
 B --> C[有界视图声明]
 C --> D[布局与组件]
 D --> E[宿主面板与对话]
 E --> F[用户确认与验收]
```

图从来源走向用户，具体业务项目的路径、模块和命令不属于这份公开图。

## 可复用实施顺序

1. 固定术语、输入输出契约、权限与来源范围。
2. 用独立合成夹具验证数据提取和视图选择。
3. 建立可复跑的布局检查与组件画廊。
4. 接入宿主面板，单独验证身份、事件和卸载生命周期。
5. 在明确支持的桌面与终端环境验证，再组织外部体验。
