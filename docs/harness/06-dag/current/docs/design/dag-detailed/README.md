## 设计方法与未附范围

早期流程包括按模块并行构思、独立审查、主线裁定、模块深化和统一口径。其目的在于让设计方明确每个区域的内容、状态与交互，减少靠猜测补齐接口的情况。原稿也记录过并行模块之间的口径差异，以及部分深化内容尚未完成第二轮审查；公开摘编不会把这些材料改称最终规格。

原始模块全文、私人会话、各轮实际索引样例、参考截图、设计底稿压缩包、导出和工作流脚本均不随本目录发布。正文若保留历史文件名或章节号，只用于理解当时设计关系，不代表相应附件存在于本仓库。公开阅读可从上表开始；新的实现应依据公开需求重新冻结协议、数据与验收范围。
