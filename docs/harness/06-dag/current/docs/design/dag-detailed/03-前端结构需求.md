## 通用页面与交互

项目图的公共界面可以围绕首页、改动影响、待决事项、架构进度及聊天中的简短证据视图组织。各页面共享卡片、边、布局和状态语义。

| 页面 | 应回答的问题 |
| --- | --- |
| 首页 | 当前关注什么、下一步去哪里 |
| 改动影响 | 修改对象会影响哪些关系，证据从哪里来 |
| 待决事项 | 哪些决定尚未作出，各选择的依据是什么 |
| 架构与进度 | 工作的结构、当前状态与缺口是什么 |
| 对话证据 | 当前回答关联哪一小块图，如何跳回来源 |

## 共同交互原则

- 使用稳定身份维护选择、后退、焦点和展开状态。
- 折叠减少内容量，保持文字尺寸和可操作区域。
- 展开卡片时尽量稳定已有拓扑，邻近对象按明确规则让位。
- 对等待、失败、缺失、过期、权限不足和未验证分别给出反馈。
- 动效用于说明状态改变，支持减少动效；不能承担唯一的信息表达。
- 桌面、窄面板和终端允许不同表达，但语义与来源保持一致。
