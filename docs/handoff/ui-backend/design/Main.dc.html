同名

组件名和状态键两端完全一样，沿用 ui-primitives 现有的名字。

同色

TUI 直接用桌面端的色值，再按 256 色、16 色逐级降。

同符号

状态靠形状区分：◐ ● ◎ ▲ ✕ ○。去掉颜色也读得出来。

同键

一个动作一个键。桌面按钮上也写出来，换端不用重学。

异形

圆角和阴影只属于桌面端。TUI 用左边条、底色、字重表达层次。
