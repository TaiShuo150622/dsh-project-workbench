落地时要知道

  • 用 dsh-tui 0.16.1 自带的解析器校验过，键名全部有效，正文对比度都在 4.5:1 以上。
  • auto 只在内置主题里切，自定义主题要自己选深色或浅色，不跟随系统。
  • permission 同时管 H2 和行内代码，所以留在蓝色系，不改成警告色。
  • 吉祥物橙和快速模式橙是品牌色，不算中性色，保留。
